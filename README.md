## Tech Stack

- **Framework**: [Next.js 14](https://nextjs.org/) (App Router, React 18, TypeScript)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/) + Custom Cyber-HUD & Scanline Utilities
- **3D Visuals**: [Three.js](https://threejs.org/) (Custom Web-Core Canvas + Fallback)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Micro-Interactions & Effects**: [canvas-confetti](https://www.npmjs.com/package/canvas-confetti)
- **Audio**: Native Web Audio API procedural synthesis (zero external audio files)

## Getting Started Locally

### Prerequisites
- Node.js 18+ (tested on Node v24.9.0)
- npm or yarn / pnpm

### Installation

1. Clone or navigate to the repository directory:
   ```bash
   cd priyanshu
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Run the development server:
   ```bash
   npm run dev
   ```

4. Open [http://localhost:3000](http://localhost:3000) in your browser.

## How to Deploy Free on Vercel

1. Push this repository to your GitHub account:
   ```bash
   git init
   git add .
   git commit -m "Initial commit: Priyanshu Ranjan Verma cinematic portfolio"
   git branch -M main
   git remote add origin https://github.com/priyanshu130018/portfolio.git
   git push -u origin main
   ```

2. Visit [Vercel](https://vercel.com/) and sign in with GitHub.
3. Click **"Add New Project"** and select your `portfolio` repository.
4. Keep the default settings (**Framework Preset**: Next.js, **Build Command**: `next build`, **Output Directory**: `.next`).
5. Click **"Deploy"**. Your portfolio will be live in under 60 seconds with free SSL, global CDN, and automatic CI/CD deployments!

## Updating Content & Projects

All resume details, project descriptions, skills, credentials, and links are centralized in a single file:

```
src/data/portfolioData.ts
```

Simply edit `PERSONAL_INFO`, `MISSIONS_DATA`, `SKILL_CATEGORIES`, `EDUCATION_HISTORY`, `ACHIEVEMENTS`, or `CERTIFICATIONS` to customize your portfolio data at any time.
